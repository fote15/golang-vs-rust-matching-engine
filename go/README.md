# Go, плоская книга

Тот же алгоритм, что в `rust/src/orderbook.rs`, на Go: прямая индексация
уровней по тику, трёхуровневая битовая карта занятости, арена ордеров на
`uint32`-индексах (без указателей — GC её не сканирует), сторона bid в
инвертированных координатах. Каталог `golang/` (код автора) не трогается;
это ответ на вопрос «а если Go-версию оптимизировать так же?».

Запуск: `./run.sh [--iters N] [--seed HEX]` — протокол автора, тот же формат вывода.
