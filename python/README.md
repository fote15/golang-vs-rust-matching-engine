# Python matching engine

Чистый CPython 3.14, без зависимостей. Запуск: `./run.sh [--iters N] [--seed HEX] [--json]`
(байткод модулей кэшируется в `build/`, запускается `python3 -OO main.py`).
Структура — как в `rust/src/orderbook.rs`: плоская книга на полосе 8192 тиков (`head[tick]`/`tail[tick]`),
арена ордеров на индексах в списках `sq`/`sn`/`ids` с интрузивным free-list, битовая карта занятости
128×64 бит + 128-битное слово; обе стороны в координатах «лучшая цена = максимальный ключ»
(bid: tick, ask: MASK^tick), лучшая цена — `int.bit_length()-1`. Горячий путь — один метод
`process_orders` с состоянием в локальных переменных, без объектов на ордер и без аллокаций в таймере.
Протокол: warmup 10k, затем ITERS свежих книг по 100k ордеров; на seed по умолчанию инварианты проверяются, при расхождении exit 1.
