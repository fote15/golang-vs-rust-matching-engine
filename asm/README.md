# ASM (ARM64 / Apple Silicon) matching engine

Сборка и запуск: `./run.sh [--iters N] [--seed HEX] [--json]` (внутри: `clang -O3 -mcpu=native main.c engine.s`, бинарник в `build/`).
Горячий путь целиком в `engine.s` (`engine_run`): матчинг, укладка остатка, битовая карта; `main.c` — генератор Xorshift64, таймер, печать, проверка инвариантов.
Входная запись ордера — 32 байта, побайтово как в Go/Rust: `u64 id @0, u64 price @8, u64 qty @16, u8 side @24` + 7 байт паддинга (`_Static_assert` в `main.c`, `ldrb` для side в `engine.s`).
Структура книги как в `rust/src/orderbook.rs`: плоская полоса 8192 тиков на сторону, уровень 16 байт (qty, head, tail),
трёхуровневая битовая карта l1/l2/l3 (лучшая цена = ctz), арена ордеров на u32-индексах с интрузивным free-list.
Сторона BID хранится в инвертированных тиках (`key = tick ^ 8191`), поэтому цикл матчинга один для обеих сторон, без ветки по side.
Все счётчики (free_head, trades, volume, resting, best обеих сторон, base) живут в регистрах весь прогон; в таймере — ни вызовов, ни аллокаций.
На дефолтном seed программа проверяет инварианты (77576 / 1973216 / 55+50 / 21620 / 10038 / 10043) и завершается с кодом 1 при расхождении.
