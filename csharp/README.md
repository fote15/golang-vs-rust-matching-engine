# C# matching engine

Сборка и запуск: `./run.sh [--iters N] [--seed HEX] [--json]` (dotnet из `/opt/homebrew/opt/dotnet/bin`,
`dotnet build -c Release` при необходимости, артефакты в `build/`). Внешних зависимостей нет.

Структура — как в `rust/src/orderbook.rs`: плоский массив уровней (16 байт) с прямой индексацией по тику
(полоса 8192 тиков от первой цены), трёхуровневая битовая карта занятости (лучшая цена — trailing zeros),
арена ордеров на 32-битных индексах с интрузивным free-list, сторона bid в инвертированных координатах
(матчинг без ветки по стороне). Вся память книги — нативные блоки, выделенные вне таймера; в горячем цикле
ни объектов, ни аллокаций, ни bounds-check (unsafe-указатели). На дефолтном seed программа проверяет
инварианты и завершается с кодом 1 при расхождении.
