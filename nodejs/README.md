# Node.js matching engine

Запуск: `./run.sh [--iters N] [--seed HEX] [--json]` (нужен только `node` v25, сборки и зависимостей нет).
Структура данных — порт `rust/src/orderbook.rs` на типизированные массивы: плоская книга с прямой
индексацией по тику (полоса 8192 тика от цены первого ордера), трёхъярусная битовая карта занятости
из 32-битных слов (лучшая цена — trailing zeros через `Math.clz32`), bid-сторона в инвертированных
координатах (одна ветка матчинга на обе стороны), арена ордеров в `Int32Array` пар (qty, next) с
интрузивным free-list по индексам. Ни одного объекта на ордер и ни одной аллокации в таймере.
Генератор Xorshift64 — на BigInt, вне таймера. Инварианты дефолтного seed проверяются, расхождение = exit 1.
