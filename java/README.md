# Java matching engine

Порт движка `rust/src/orderbook.rs` на Java (JDK 26, только стандартная библиотека, один файл `Main.java`).
Запуск: `./run.sh [--iters N] [--seed HEX] [--json]` — компилирует в `build/` при необходимости и запускает
`java -XX:+UseSerialGC -Xms512m -Xmx512m -XX:+AlwaysPreTouch -cp build Main`.
Структура: плоская книга с прямой индексацией по тику (полоса 8192 тиков от цены первого ордера), SoA-массивы
уровней `long[] qty / int[] head / int[] tail`, трёхуровневая битовая карта занятости (лучшая цена — `numberOfTrailingZeros`),
bid-сторона в инвертированных координатах (горячий путь без ветки по стороне), арена ордеров на `int`-индексах с интрузивным free-list.
В таймере — только цикл `processOrder`; книга и все массивы создаются заранее, аллокаций в горячем пути нет.
Инварианты дефолтного seed проверяются после прогона; при расхождении — exit 1.
