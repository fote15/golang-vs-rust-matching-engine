# PHP matching engine
`./run.sh [--iters N] [--seed HEX] [--json]` — сборки нет; скрипт запускает `/opt/homebrew/opt/php/bin/php engine.php`
с OPcache JIT `opcache.jit=1054` (tracing без распределения регистров: режимы с регистрами в PHP 8.5.10/arm64 на этом
коде дают неверный результат на части seed, что ловит встроенная проверка инвариантов). Зависимостей нет.
Книга — как в `rust/src/orderbook.rs`, но на плоских packed-массивах `int`: полоса 8192 тиков с прямой индексацией
(bid — в инвертированных координатах, лучшая цена = минимум), трёхуровневая битовая карта на 32-битных словах
(ctz через `w & -w` + LUT), арена ордеров qty/next/id на целочисленных индексах с интрузивным free-list; горячий цикл —
в одной функции на локальных переменных, без объектов и аллокаций в таймере. Xorshift64 — знаковые int с масками, вне таймера.
